# Poulomi Florique responsive image pack

This pack combines the project imagery already used on the current Poulomi Florique site with newly generated supporting lifestyle imagery for the Botanical Editorial Luxury direction.

Folders:

- `official/`: factual project imagery copied from the current site.
- `generated/`: full-resolution generated supporting masters.
- `optimized/`: production-oriented WebP crops.
- `decorative/`: lightweight botanical SVG details.
- `placeholders/`: reserved for additional official assets from the sales/design team.

Start with `ASSET-MANIFEST.md` for exact placement, breakpoints and alt text.
